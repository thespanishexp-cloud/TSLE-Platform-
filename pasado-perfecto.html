Referencia rápida: el pasado perfecto (pluscuamperfecto)

Haber en imperfecto + participio pasado:

Pronombrehaber+ participio
yohabíahablado / comido / vivido
túhabíashablado / comido / vivido
él/ella/ustedhabíahablado / comido / vivido
nosotroshabíamoshablado / comido / vivido
ellos/ustedeshabíanhablado / comido / vivido
Participios irregulares:
hacer → hecho decir → dicho ver → visto poner → puesto escribir → escrito abrir → abierto volver → vuelto romper → roto

Se usa para hablar de una acción que ya había ocurrido antes de otra acción pasada: "Cuando llegué, ellos ya habían salido."
