Referencia rápida: el subjuntivo perfecto (pretérito perfecto de subjuntivo)

Se forma con el presente de subjuntivo de haber + el participio pasado:

Pronombrehaber+ participio
yohayahablado / comido / vivido
túhayashablado / comido / vivido
él/ella/ustedhayahablado / comido / vivido
nosotroshayamoshablado / comido / vivido
ellos/ustedeshayanhablado / comido / vivido
Participios irregulares:
hacer → hecho decir → dicho escribir → escrito ver → visto poner → puesto volver → vuelto abrir → abierto romper → roto

Se usa cuando la acción de la que se duda, se espera o se alegra ya sucedió (o se supone que ya sucedió) antes del momento en que se habla: "Espero que hayas dormido bien."
